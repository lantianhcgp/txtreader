TXTreader for WATCH GT5 — 更新日志
===================================

v2.0.0 — 2026-10-14  (GT5 适配版)
------------------------------------

【迁移】
- 构建链：DevEco 3.1 Gradle（hap 3.1.5.0 / compileSdkVersion 5）→
  hvigor / CLT 6.1.1（faMode，modelVersion 6.1.1），GitHub Actions 一键出包
- config.json：迁移为 hvigor FA 形态（abilities .MainAbility +
  srcLanguage/srcPath），版本 2.0.0
- SDK 声明：compatibleSdkVersion 4.0.0(10) + targetSdkVersion 6.1.1(24)
  （GT5 = API 10+ 档机型要求）
- JS API：requireNative('system.file'/'system.storage') →
  import file from '@system.file' / import storage from '@system.storage'
- 按钮：input type=button → div+text+@click（官方引擎点击行为双证模式）

【界面 — WATCH GT5 466x466 圆屏】
- 画布 454x454 → 466x466
- 正文列 336px / 字号 28px / 12 字一行 / 8 行一页（96 字/页，密度同原版）
- 圆安全区重排：标题栏、正文、两侧翻页热区、底部按钮行逐段按弦宽核算，
  全部元素四角在圆内；原版底部按钮外角被圆裁切的问题一并修正
- 底部按钮行 360px → 294px（3x86），y 364..412

【新增】
- IO 挂死兜底（elcton 同款模式）：异步旅程 1s 看门狗，超时进演示模式（标题带 (demo)），
  演示文本走同一套分页/翻页路径；真机回调毫秒级到达时兜底永不触发
- 跨区块读取超时提示「timeout 点击重试」，不再静默吞页

【不变】
- 3000 字节分块异步读取（64KB 级堆也能啃 22 万字大书）
- 进度记忆 prevChunkStart:pg:charPos，每 5 页自动保存，换书自动清零
- 目录浏览 / 侧边+底部双翻页 / Reset 双态
- v1.1.0 的全部竞态修复（loadingChunk 互斥、999 末页裁剪、不等长分页等）
